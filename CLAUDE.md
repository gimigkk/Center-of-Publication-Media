# COPM (Creative Ops Project Manager)

Kanban-based job & design request tracker.

## Tech Stack
- **Framework**: Next.js (App Router), React 19, TypeScript
- **Database & Auth**: Supabase, Postgres, Drizzle ORM
- **Styling**: Vanilla CSS (modular stylesheets under `src/styles/`)

## Common Commands
- `npm run dev`: Start local development server
- `npm run build`: Build production bundle / validate types
- `npm run lint`: Run ESLint checks
- `npm run db:push`: Push Drizzle schema changes
